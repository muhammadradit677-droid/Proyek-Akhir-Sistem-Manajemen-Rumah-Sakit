Proyek ini mengembangkan Sistem Manajemen Rumah Sakit Terintegrasi berbasis C++ untuk mengatasi masalah administrasi konvensional, khususnya penumpukan antrean pasien dan penjadwalan medis yang tidak efisien.
Tahap 1: Login Portal Program akan meminta kredensial terlebih dahulu. 
Masukkan Username: admin atau doctor
Masukkan Password: 1234
Tahap 2: Menggunakan Menu Utama Jika login sukses, program akan memunculkan 10 pilihan menu utama. Ketik angka 1 sampai 10 sesuai fitur yang ingin Anda uji, lalu tekan Enter.
Uji Coba Pertama: Sangat disarankan untuk memilih menu nomor 1 terlebih dahulu untuk menginput beberapa data pasien. Jika data masih kosong, menu visualisasi (seperti menu 2 atau 3) tidak akan menampilkan data apa pun.
